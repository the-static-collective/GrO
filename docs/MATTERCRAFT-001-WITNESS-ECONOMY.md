# MATTERCRAFT 001 — GrO notices what the world might become

**Status:** GrO-native, executable **read-only source-addressed HOLD**. Does not onboard any institutions, mint assets, physically witness, deliver supplies, reward a person, execute a transformation, register a real location, or call PENNY, Full Measure, reLATTE, GHoT, JAR;VIS or STATIC OS APIs.

## Why GrO is the missing surface

Full Measure owns the *inhabited participation and genuine human-witnessed consequence*. PENNY/Jubilee owns *typed material inventory, authorized commitments, custody and settlement boundaries*. reLATTE conveys *permissioned crossings between independently governed receivers*. JAR;VIS/planZ propose bounded work. STATIC OS provides a *candidate offline household for the tools*. GrO turns those artifacts into **encounters in a locality**.

Its original rule remains: **THE MAP IS NOT CONTENT. THE MAP IS CONSEQUENCE.**

A GrO location's possible next actions depend on particular local facts, history, and permission. This branch does not project an economic promise into actual stock or let a game reward override human decisions. Its effect is one additional, actor-local **encounter** in the existing native `resolveField()` projection. `act()` cannot execute the encounter.

## First test: the 42 WOOD world

1. A fictional steward declares `42 wood-bundle` under an explicitly **unverified** unit standard, resource ID and locality. `digestClaim` commits the exact JSON fields and `expectedClaimSha256` must match. This is integrity only, not a signature or physical verification.
2. A fictional observer candidate reports **39** by hand count and refers to a purported evidence digest; no proof of independently owned observer key or actual photo bytes exists. GrO shows **COUNTS_DISAGREE_HOLD**. It cannot set recognized spendable inventory above zero.
3. Full Measure can later offer a separately authorized *verification quest* and review an actual independent witness: here it is `HOLD_NOT_AWARDED`, not a Deed.
4. A banana can be an optional **unfunded, non-coercive appreciation proposal**. It cannot pay itself, deliver a banana, create a wage exemption, or condition necessities on participating.
5. A proposed `4 WOOD → ASH + HEAT + OTHER COMBUSTION PRODUCTS` is a **what-if only**. Wood inventory is not retired; heat is not measured; ash is not minted or assumed safe for soil or food growing; all output quantities stay unknown pending safe observations.
6. The encounter is private and no automatic trace, network message, resource consumption, credit, public location or payment is emitted.

Run:

```sh
node examples/mattercraft-001.js
node --test test/mattercraft-001.test.js
npm test
```

All values are synthetic. JSON content addresses have neither third-party custody nor owner authorization. Never treat a photograph alone as title or genuine physical inventory.

## Next proof ladder (separate reviews)

**1. Real public-safe local unit standard.** Define firewood with dimensions, allowable packing gaps, species and moisture reporting; do not assume a 'breadbox' establishes fuel equivalence. Alternative small pieces require a reproducible measurement; dividing one log does not multiply biomass.

**2. Qualified human permission.** Confirm steward authority, land access and opt-in consent. Institutions may be witness *candidates*; university/church/emergency branding does not prove authority. No sensitive locations or affiliations published.

**3. Device-local evidence, not automatic truth.** Witness photo/measurement kept privately under a steward-approved process; independent challenge, dispute and appeals. No universal reputation or tracking of vulnerable people.

**4. Source-owned accounts.** Produce an authenticated resource claim from PENNY (or compatible owner-local inventory) and a separate signed receipt after real custody review. A local GrO notice changes no ledger.

**5. Native cross-org transport.** A real reLATTE receiver separately HOLDs or admits an exact proposal under destination permission; only the source owner changes custody/stock. Offline partitions cannot guarantee global no-double-spend.

**6. Verified real transformation.** Monitor actual material input, output and loss within appropriate safety controls; no dangerous burning needed for a first field trial—count or divide firewood on a permitted indoor table.

**7. Real world consequences.** Full Measure's separately governed human-witnessed Deed may enable a new GrO affordance; the network can publish a reusable public-safe method only after permission. Reward delivery requires a separate real resource and appropriate stewardship/legal/compensation review.

**8. Physical infrastructure.** An offline phone+Suitcase+router station is a later integration test, not this experiment's proven deployment.

## Constitutional boundary

`CLAIM != INVENTORY` · `HASH != SIGNATURE` · `OBSERVATION != TRUTH` · `WITNESS ID != INDEPENDENCE` · `QUEST != TASK ASSIGNMENT` · `REWARD CANDIDATE != PAYMENT` · `TRANSFORM PREVIEW != FIRE` · `WOOD != ASH` · `GRo NOTICE != RESOURCE AUTHORITY` · `ADMISSION != DEED`.

The user-facing vision: **Walk outside, encounter what is locally possible, safely take part by choice, and see the world's legitimate next possibilities change because of real, separately verified consequences.**
