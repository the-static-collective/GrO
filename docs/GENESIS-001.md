# GENESIS 001 — The map is consequence

Status: executable specimen

## Claim under test

GrO's smallest honest world-changing loop is not:

```text
walk → collect point → increment account
```

It is:

```text
actor A encounters place
  ↓
place affords bounded action
  ↓
actor A acts
  ↓
occurrence receives attributable receipt
  ↓
trace remains locally relevant
  ↓
actor B encounters same place
  ↓
actor B + held particular + trace resolve a new affordance
```

The new affordance did not need to be manually spawned by a global game master.

## Hard separation

```text
ACT ≠ RECEIPT ≠ VALUE ≠ AUTHORITY ≠ OWNERSHIP
```

GENESIS 001 only proves occurrence and attributable causal influence.

It does **not** claim that caring for a place:
- creates money;
- establishes ownership;
- grants governance authority;
- creates reputation;
- proves moral worth;
- forces a later actor to take the newly available action.

## Why the later actor matters

If the only result of an action is that the original player's account changes, GrO has not yet produced ecological inheritance.

The proof becomes interesting when one actor's action changes another actor's later field without transferring identity, authority, or ownership.
